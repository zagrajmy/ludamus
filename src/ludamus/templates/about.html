{% translate "About Zagrajmy" %}

{% translate "Zagrajmy is an event programme platform that runs proposals, the schedule, enrollment, and print for organizers of conventions, conferences, and meetups." %}

{% translate "Bring the event. We help set up proposals, programme, enrollment, and the public page in Zagrajmy." %}

{% translate "What Zagrajmy does" %}

{% translate "Programme proposals and review" %}

{% translate "Programme creators send proposals through a form with your own questions. Every proposal lands in one inbox, where your team accepts it, puts it on hold, or rejects it." %}

{% translate "Scheduling" %}

{% translate "You build the grid from tracks, rooms, and time slots. Two programme items in one room at the same time? Zagrajmy highlights the conflict before attendees see it." %}

{% translate "The event page" %}

{% translate "Attendees get one address with the current programme, descriptions, and free seats. A change made in the organizer panel shows up on the page right away." %}

{% translate "Enrollment and waiting lists" %}

{% translate "You set seat limits, and Zagrajmy runs enrollment and the waiting list. When a seat frees up, the next person in line gets it without anyone rewriting a list by hand." %}

{% translate "Print" context "landing walkthrough step" %}

{% translate "The full schedule, day plans, and door cards for every room print straight from the browser. A programme change means a fresh printout instead of an evening of rebuilding files." %}

{% translate "Encounters" %}

{% translate "Players post a game night, send friends one link, and see who is coming and how many seats are left. It needs no organizer and no setup." %}

{% translate "What makes Zagrajmy different" %}

{% translate "We set up your event with you" %}

{% translate "Most event tools hand you an empty account and a help centre. We start with a call about how your event works and prepare the first version of proposals, rooms, and time slots together with you." %}

{% translate "Groups stay together on the waiting list" %}

{% translate "Friends who enroll together wait together and move up together, and nobody skips past them. RSVP tools that count seats one by one split such a group up as soon as a single seat frees up." %}

{% translate "Your spreadsheet is a starting point" %}

{% translate "If your programme already lives in Google Sheets or Google Forms, we import it instead of making you retype it. A finished programme can also be exported to Konwencik." %}

{% translate "Open source, no lock-in" %}

{% blocktranslate trimmed with source_url="https://github.com/zagrajmy/ludamus" %} All of Zagrajmy's code is public on GitHub under the AGPL-3.0 license. Your programme is never locked in a closed service: you can take it and run Zagrajmy yourself. {% endblocktranslate %}

{% translate "Free for attendees and small meetups" %}

{% translate "Attendees never pay Zagrajmy to enroll, and small meetups and Encounters cost nothing. Conventions and conferences get a written proposal before anything is agreed." %}

{% translate "Who uses Zagrajmy" %}

  • {% translate "Organizers of fan conventions (board games, RPGs, fantasy) with a multi-day programme across many rooms" %}
  • {% translate "Conference organizers who collect talk proposals and build a room grid" %}
  • {% translate "Organizers of meetups and clubs who need an event page with seat limits" %}
  • {% translate "Programme creators and game masters who submit programme items to an event" %}
  • {% translate "Attendees who enroll in programme items, alone or with friends" %}
  • {% translate "Players who invite others to a game night with an Encounter" %}

{% translate "Frequently asked questions" %}

{% translate "Is Zagrajmy only for board games and RPGs?" %}

{% translate "No. It grew out of tabletop game conventions, but talks, workshops, and panels fit the same programme. Rooms, tracks, time slots, and seat limits work the same way for any kind of programme item." %}

{% translate "Can I set up an event on my own?" %}

{% translate "A convention or conference we set up together with you, so the first version fits how your event works. A game night you can post yourself as an Encounter, right away and for free." %}

{% translate "How much does it cost?" %}

{% translate "Small meetups — free. For conventions and conferences we agree on terms matched to the scale of the event; before you decide anything, you get a concrete written proposal." %}

{% translate "Do I have to retype everything from spreadsheets?" %}

{% translate "Zagrajmy can collect session proposals, but it can also import your existing data from Google Sheets. You come in with what you already have instead of starting from an empty table." %}

{% translate "Do attendees need an account?" %}

{% translate "Not to browse the programme. To enroll, yes: signing in takes a minute, and a nickname is enough as a name." %}

{% translate "Can I run Zagrajmy on my own server?" %}

{% translate "Yes. The code is public on GitHub under the AGPL-3.0 license, so you can run your own copy. If you change it and offer it to others, the license asks you to share those changes too." %}
