{% comment %}The shell's bar reserves 12px around the tabs so a raised tab clears a rounded, bordered card edge. The panel strips that edge — rounded-t-none at every width, border-0 below — so the top 12px is a bare band of tab-track colour on desktop too, and `pt-1.5` is deliberately unprefixed. The sides only close up below sm, where the band costs viewport width; the tab body edge moves with them, since the first tab is meant to sit flush with the content under it. Never the bottom, at any width: the selected tab is pulled a pixel over the bar's border to read as attached to the panel below, and padding under it floats the whole strip off its rail. Pages that run their cards to the viewport edge below sm mark their wrapper `.panel-bleed`; the rules live in index.css next to `.card`. {% endcomment %}
{% comment %}Header CTAs go icon-only below sm — the glyph carries the action and the title beside it gets the width back. The label goes sr-only rather than hidden, so the button keeps its accessible name. Templates and `tessera_button` both mark it `.btn-label`; the breakpoint is decided here, once, rather than in 28 templates. The first three rules hang off the same `:has(>svg)`, and must keep doing so. A button with no icon has nothing to fall back on, so hiding its label leaves a blank pill — which is what the moderation bar on proposal-detail (Accept / Hold / Reject / Delete) would become. The same guard covers `{% templatetag openblock %} icon {% templatetag closeblock %}` returning "" for a missing icon in production. `min-h-11` is the one rule that covers every button: an iconless one keeps its label and its own width, but `py-2` alone leaves it 38px — under the tap-target floor, and 6px shy of the squares it sits beside. Stated as a minimum rather than a height so it never argues with `size-11` over the icon buttons. `w-auto` is deliberately ungated: `tessera_button` stretches every form-submit button by default, which is right in a body form and never right in this strip. Deciding it here spares 22 header templates from each passing `full_width_mobile=False`. {% endcomment %}
