On an avatar it sits next to the warning badge (components/avatar.html), which is the same 14px box with the same knockout ring, so sharing the corner shape makes the two read as a matched pair instead of two unrelated stickers. The plate is white in both themes: an uploaded mark is often a dark silhouette on transparency, which would vanish against the dark card surface. The image fills the plate so full-bleed uploads visibly inherit its squircle. `object-contain` keeps non-square marks uncropped. `title` names the guild on hover: at this size the mark alone is a puzzle for anyone who does not already know the crest. It matches `alt` word for word, so a screen reader that reads both does not read two different things. Hover only, so it is a bonus on top of the name `alt` already gives, not the only way to learn whose crest this is. The plate carries `z-20 pointer-events-auto` itself. Every schedule surface lays a full-bleed session link (z-10) over the card, and a native tooltip on an element under that link can never fire — the rule _proposal_slot.html states for its own meta row. The mark is the deliberate exception: it is an object in its own right, the way the bookmark toggle is. Unlike that toggle the mark does nothing when clicked, so the cost is real: its own few pixels stop opening the session, and on touch, where there is no hover, they buy nothing. `z-index` needs a positioned box, so a caller whose mark is not already absolute passes `relative`.
