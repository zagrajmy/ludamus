{# Select element. Two modes: #} {# Tag mode ({% select %}): attrs (safe string), extra_class, has_errors, slot (safe string) #} {# Form mode (render_select): name, id, choices, selected, required, has_errors, disabled, aria_describedby #} {# has_errors carries both cues in either mode — the red border and aria-invalid. #} {# Form mode also takes inplace_class: the in-place look, from tessera `inplace_look`. #}
