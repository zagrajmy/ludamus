# Proposing through open calls

## Entry

As a proposer, I want one address for proposing at an event, so that a
link shared once keeps working whatever calls are open.

As a proposer, I want proposing refused when no call is open, with the next
opening shown when one is scheduled, so that I know when to come back.

As a proposer, I want to read the descriptions of the open calls before I
start, so that I know what the organiser is looking for.

## Choosing a kind

As a proposer, I want to choose among every kind any open call accepts, so
that I see everything on offer.

As a proposer, I want the kind chosen for me when only one is open, so that
I am not asked a question with one answer.

As an anonymous proposer, I want to propose a kind without an account when
an open call accepting that kind allows it, so that the lowest barrier
wins.

## Reading kinds elsewhere

As a participant, I want to filter the programme by kind, so that a closed
call changes nothing about browsing.

As an automation client, I want to list and create kinds regardless of any
call, so that seeding an event works before intake opens.
