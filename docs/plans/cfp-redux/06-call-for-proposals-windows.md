# Call for proposals windows

## Opening

As an organiser, I want to open a call for proposals with a start, an end,
a description for proposers, and whether anonymous proposals are allowed,
so that one thing holds the whole invitation.

As an organiser, I want to choose which kinds a call accepts, so that I can
open workshops in spring and talks in summer.

As an organiser, I want several calls open at once, so that different kinds
can run on different schedules.

As an organiser, I want a call whose end precedes its start refused, so
that I cannot save a window that never opens.

## Managing

As an organiser, I want to see every call with its period, kinds,
anonymity, and whether it is upcoming, open, or closed, so that I know the
state of intake at a glance.

As an organiser, I want to change or remove a call, so that a mistake is
fixed without starting over.

As an organiser, I want the intake I had configured before this change
carried over as one call covering every kind, so that nothing opens or
closes by surprise.

As an operator, I want call changes recorded, so that I can see who opened
or closed intake.
