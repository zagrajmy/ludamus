# Multi-bucket sessions

## Turning it on

As an organiser, I want to choose per event whether a session sits in one
bucket or in several, so that I can run buckets as a pipeline or as a
checklist depending on the event.

As an organiser, I want the setting explained in terms of what changes,
so that I can pick without trying both.

## Working with several buckets

As a reviewer, on an event that allows several buckets, I want to tick and
untick buckets on a session, so that I can record every step it has passed.

As a reviewer, I want to filter the session list by several buckets at
once, so that I can find sessions that passed some steps but not others.

As an organiser, I want a session on the timetable to always keep at least
one ready-to-plan bucket, so that the checklist cannot untick its way off
the timetable.

As an organiser, I want a session's several buckets shown compactly with
their icons, so that a long checklist does not swamp the list.

## Turning it off

As an organiser, I want to be refused when I turn the setting off while
sessions still hold several buckets, and told how many, so that I never
lose recorded steps silently.
