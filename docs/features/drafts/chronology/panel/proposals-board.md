# Proposals board

## Seeing the workflow

As a reviewer, I want to view the session list as one column per bucket,
in bucket order, so that I can see the whole workflow at once.

As a reviewer, I want to switch between the table and the board without
losing my filters, so that the board is another way of looking at the
same set.

As a reviewer, I want an empty column to say so, so that I can tell an
empty step from a loading one.

## Moving on the board

As a reviewer, I want to move a session to another bucket from its card,
so that I can triage without leaving the board.

As a reviewer, I want a session on the timetable to refuse a move to a
bucket that forbids planning, with the same message as elsewhere, so that
the board enforces the same rules as the rest of the panel.

As a reviewer using assistive technology, I want to move a session between
columns by keyboard, so that the board is not limited to mouse users.

As a reviewer, I want the board to remember which view I last used on this
event, so that I do not switch back every visit.
